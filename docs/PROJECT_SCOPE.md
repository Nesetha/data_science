# Project scope

## Implemented
- Ultrasound image upload and preview only.
- Educational local research-text retrieval.
- Optional Ollama text generation.
- PDF text extraction/indexing.
- Basic phrase-based safety smoke checks.
- Local JSON research-intake records.
- FastAPI and Streamlit interfaces.

## Not implemented or validated
- Spina Bifida detection.
- Clinical diagnosis or treatment recommendations.
- Trained fetal ultrasound classifier.
- Grad-CAM or calibrated uncertainty.
- Production-grade RAG evaluation.
- MongoDB persistence integration in the UI.
- OpenAI integration (requires API credentials).
- Clinical validation or regulatory clearance.

Do not describe this as a Spina Bifida detector until suitable labelled data, rigorous patient-independent evaluation, external validation, and qualified clinical review support that claim.
